# 3D Contribution Tower maintenance

The profile embeds real GitHub contribution calendars generated by
[github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib)
v0.9.3, pinned to its full commit SHA. Layout follows the
[3D Contribution Tower template](https://github.com/beydemirfurkan/awesome-github-profile/tree/main/templates/03-3d-immersive/3d-contribution-tower).

## Refresh

- Workflow: `.github/workflows/profile-3d.yml` / **GitHub-Profile-3D-Contrib**.
- Scheduled daily at 05:17 UTC (10:17 UTC+5); scheduled jobs may be delayed.
- Manual: Actions → GitHub-Profile-3D-Contrib → Run workflow → select `main`.
- Workflow-file pushes also run generation on their own branch, allowing checks
  before merging. Only generated SVGs are committed; no force push is used.
- Scheduled workflows must exist on the default branch. GitHub can disable
  scheduled workflows in inactive public repositories; re-enable in Actions if needed.

## Appearance and data

`README.md` uses a full-width `<picture>` with these repository-local files:

- Dark: `profile-3d-contrib/profile-night-rainbow.svg`.
- Light: `profile-3d-contrib/profile-season.svg`.
- Fallback: night rainbow.

The generator also emits its other standard SVG themes in the same directory.
All use GitHub data for `bekzatwr`; no synthetic counts are added. Private
repository details are not requested with a personal token. The built-in token
has the visibility provided by GitHub; this is not a guarantee of complete
private-repository activity. The image is a contribution calendar, not a measure
of project quality, hours worked or professional experience.

## Permissions and troubleshooting

The job uses only the built-in `secrets.GITHUB_TOKEN` with `contents: write`.
No new PAT, repository secret or external rendering service is required.
The repository's default token setting can stay read-only: this workflow requests
the specific permission it needs. Organization policy or branch protection can
still restrict writing. If a run fails, inspect its logs before changing settings.

- Generate step fails: check Actions availability, API errors and the pinned action.
- Push returns 403: check effective job token permissions, organization policy,
  and branch/ruleset restrictions. Do not disable protections automatically.
- Push is rejected after a concurrent edit: rerun on the latest branch.
- README image missing: verify both SVGs exist on the branch being displayed.
- Scheduled refresh stopped: check that the workflow is enabled in Actions.

The workflow validates both displayed SVGs before committing. GitHub's image
cache can briefly show an older version after a successful update.
