# Typewriter Intro

Source: [original template](https://github.com/beydemirfurkan/awesome-github-profile/tree/main/templates/02-animated/typewriter-intro)
and [original SVG](https://github.com/beydemirfurkan/awesome-github-profile/blob/main/assets/animated/typewriter-intro.svg).
Upstream SVG Git blob: `6563d9c9f3dad1e120cfcb062e2b1fd4c67ffa34`.
The upstream repository license is preserved in `assets/typewriter-intro.LICENSE`.

`assets/typewriter-intro.svg` is the original 1200 × 420 SVG with personalized
text only. All element attributes, coordinates, colors, shadows, traffic lights,
font families and SMIL animation remain unchanged. The three unused example
contact strings are empty; only the confirmed GitHub profile is shown.

The cursor uses the original 1.1-second repeating square-wave opacity animation.
There is no simulated typing effect: the original template animates only the cursor.
No external fonts, scripts, images or typing services are loaded by the SVG.

The README shows the SVG at 100% width. The previous `header-v2.svg` and
`header.svg` files are retained, but the old hero is no longer embedded.
The 3D Contribution Tower block, generated SVGs and daily generation workflow
were removed at the owner's request. No Actions job is needed for this intro.
